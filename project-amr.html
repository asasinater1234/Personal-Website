// Robotics · Autonomous Systems · NUS CDE2310

Autonomous Payload Delivery AMR

A TurtleBot3-based autonomous mobile robot that maps unknown mazes via SLAM, detects ArUco marker targets with computer vision, and deploys a flywheel-launched payload on arrival

NUS CDE2310 — Group Project ⏏ GitHub — View Code

// 01 — Overview

What Is It?

The Autonomous Payload Delivery AMR is a fully autonomous mobile robot built on the TurtleBot3 platform for the NUS CDE2310 module. Given no prior knowledge of its environment, the robot explores an unknown maze in real time using 2D LiDAR-based SLAM, building a map as it moves.

When its onboard camera detects an ArUco fiducial marker — the delivery target — the robot transitions from exploration mode to docking and delivery mode, aligns precisely with the target station, and launches ping pong balls through a custom flywheel mechanism. The entire mission cycle runs without human input, coordinated by a Finite State Machine managing all operating modes.

01

Autonomous Maze Exploration

The robot uses 2D LiDAR with frontier-based SLAM to explore an unknown environment in real time, building an occupancy grid map and navigating to unmapped frontiers until the full maze is charted.

02

Vision-Based Target Detection

While exploring, the onboard Raspberry Pi camera continuously scans for ArUco fiducial markers using OpenCV. On detection, the FSM triggers a mode switch — the robot halts exploration and begins aligning to the target station.

03

Payload Deployment

Once docked and aligned, a MOSFET-controlled DC flywheel motor spins up and a servo-driven feeder mechanism releases ping pong balls into the launcher, delivering the payload to the target. The 9-ball reservoir completes the full mission cycle autonomously.
